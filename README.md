### Olá, eu sou o Guilherme 👋

Desenvolvedor front-end na [Nova Studio](https://github.com/novastudio-br), onde construo as telas do **FlowRecon**, um SaaS de conciliação financeira e emissão fiscal para e-commerce. Gosto de interface que resolve o problema sem pedir manual: hierarquia clara, estados vazios bem pensados e tela que funciona no celular.
